# Shop Inventory Management MERN Project

## Frontend

Install packages

```bash
npm install
```
Run fronted

```bash
npm run dev
```

By default the Vite dev server proxies `/api` to `http://localhost:8000`.
If your backend is running on another port in PowerShell:

```powershell
$env:VITE_API_PROXY_TARGET="http://localhost:8001"; npm run dev
```
